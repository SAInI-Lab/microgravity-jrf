# JRF application: aging, microgravity and drug screening

Application site for a Junior Research Fellowship at [SAInI's Lab](https://sites.google.com/site/sainislab/home), Indian Institute of Science, Bengaluru (ISRO collaboration).

A static page served by GitHub Pages. Applicants answer fifteen questions counting down from T−15, pass a go/no-go check and an AI declaration, then launch. Submissions go to a Google Sheet through the Apps Script in [`apps-script/`](apps-script/README.md).
